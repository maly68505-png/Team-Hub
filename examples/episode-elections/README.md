# استمارة مونتاج — الانتخابات الفلسطينية

البيانات دي مستخرجة من ملف `استمارة مونتاج الانتخابات التشريعية.pdf`.

| الملف | المحتوى |
|---|---|
| `episode-info.txt` | عنوان الحلقة، المقدم، والضيوف الثلاثة |
| `chapters.csv` | ٧ محاور الحلقة بتوقيتاتها |
| `quotes.csv` | ٩ اقتباسات هتظهر مكتوبة — **عمود المتحدث فاضي، محتاج يتملى** |
| `quotes.srt` | نفس الاقتباسات بصيغة الأداة — **أسماء المتحدثين لسه `PERSON_?`** |
| `visuals.csv` | ٢١ معادل بصري بتوقيتاته و‑٢٤ رابط صورة |
| `cuts.csv` | جدول مقاطع الحذف |

## ملاحظات مهمة

**التوقيتات دي بتاعة الحلقة الأصلية (٢ ساعة و٢٢ دقيقة)، مش بتاعة الكومب.**
لو الكومب بتاعك بيبدأ من نقطة تانية، لازم تزحزح التوقيتات.

**الاستمارة فيها توقيت بداية بس، مفيش نهاية.** ملف `quotes.srt` مفترض
إن كل اقتباس مدته ٨ ثواني — عدّلها على كيفك.

**الاستمارة مش بتقول مين قال كل اقتباس.** ده الجزء الوحيد اللي مش موجود
في الملف الأصلي، ومحتاج يتحدد يدوياً قبل ما الأداة تعرف تشتغل.

النص العربي هنا مُصحَّح يدوياً: استخراج النص من PDF بيكسّر حرف «لا»
ويحوّله لـ «ال»، فالكلام اتقرا واتصلّح على المعنى.
