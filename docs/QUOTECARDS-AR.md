# مولّد كروت الاقتباسات

الملف: **`QuoteCards.jsx`**

بياخد **كومب قالب واحد** ويعمل منه **نسخة لكل اقتباس** — كل نسخة بفيديو متحدث مختلف ونص اقتباس مختلف.

---

## ١. جهّز الكومب القالب

الكومب اللي عندك (`اقتباس`) لازم يكون فيه:

- **طبقة فيديو** للمتحدث — بالماسك والإفكتات اللي إنت عاملها، عادي
- **طبقة نص** للاقتباس — بالخط واللون والحجم اللي إنت مظبطهم

> **القالب نفسه مش بيتغير أبداً.** كل كرت بيتعمل كنسخة مستقلة منه.

---

## ٢. رتّب الكليبات بالترتيب

**ترتيب الملفات في الفولدر هو اللي بيحدد مين يظهر في أي اقتباس:**

| الكليب | يروح لـ |
|---|---|
| أول كليب | الاقتباس ١ |
| تاني كليب | الاقتباس ٢ |
| تالت كليب | الاقتباس ٣ |
| … | … |

فأسهل حاجة تسمّي الملفات بأرقام:

```
Aktbas/
   01_دلال.mp4
   02_مشينش.mp4
   03_محارمة.mp4
   ...
```

الترتيب طبيعي ومظبوط: `clip2` بييجي قبل `clip10`، مش بعده.

---

## ٣. ملف الاقتباسات

الأداة بتقبل تلات صيغ:

| الصيغة | إزاي بتقرأها |
|---|---|
| `.csv` | بتاخد العمود اللي فيه أطول نصوص — يعني ملف `quotes.csv` اللي عملتهولك شغّال على طول |
| `.txt` | كل اقتباس في فقرة (سطر فاضي بينهم)، أو كل اقتباس في سطر |
| `.srt` | بتاخد سطر `# ...` اللي تحت كل توقيت |

---

## ٤. شغّل

1. افتح الكومب القالب
2. **File ← Scripts ← Run Script File…** ← اختار `QuoteCards.jsx`
3. في النافذة:
   - **Template comp** — الكومب القالب
   - **Clips folder** — فولدر الكليبات
   - **Quotes file** — ملف الاقتباسات
   - **Video layer** — طبقة الفيديو (بتتحدد لوحدها، غيّرها لو غلط)
   - **Text layer** — طبقة النص (بتتحدد لوحدها، أو اختار «اتركه» لو مش عايز يغيّر النص)
4. الجدول بيتملى **لوحده** أول ما التلات خانات تتحدد — كل اقتباس جنبه الكليب اللي هياخده. لسه مفيش حاجة اتعملت
5. **Create cards** — بيعمل الكروت

> لو الجدول فاضي والزرار مقفول، اضغط **Scan** يدوي. والسطر اللي تحت الجدول بيقولك السبب دايماً.

الكروت كلها بتتحط في فولدر واحد في الـ Project panel اسمه `<اسم القالب> - cards`.

---

## اللي بيحصل في كل كرت

- نسخة من الكومب القالب باسم `اقتباس 01`، `اقتباس 02`، …
- فيديو المتحدث اتبدّل في نفس الطبقة ← **الماسك والإفكتات والتحريك كلهم زي ما هم**
- نص الاقتباس اتكتب ← **الخط واللون والحجم والمحاذاة زي ما هم**
- لو فعّلت خيار الماتّ: طبقة `[MATTE]` فوق الفيديو، متوصّلة كـ alpha track matte مع Simple Choker و blur لضبط الحواف

`Ctrl+Z` مرة واحدة بترجّع كل الكروت.

---

## مهم للنص العربي

عشان العربي يظهر صح، لازم محرك النص الشرق أوسطي مفعّل:

**Preferences ← Type ← Text Engine ← South Asian and Middle Eastern**

لو كان مقفول، فعّله وأعد تشغيل After Effects **قبل** ما تشغّل الأداة.

---

## لو حاجة مظبطتش

| المشكلة | الحل |
|---|---|
| `-- no clip --` في عمود Clip | عدد الكليبات أقل من عدد الاقتباسات. زوّد كليبات أو قلّل اقتباسات |
| `The template comp has no footage layer` | الكومب المختار مفيهوش طبقة فيديو. اتأكد إنك مختار الكومب الصح |
| `-- no text layer in this comp --` | الكومب مفيهوش طبقة نص. غالباً النص جوه **precomp** (افتحه واشتغل عليه)، أو هو **shape layer** مش text layer |
| النص مش بيتغير | اختار طبقة النص الصح من **Text layer** — لو سايبها على «leave the text alone» مش هيتكتب حاجة. ولو النص عليه كي فريمز، الأداة بتسيبه وبتكتب ده في اللوج |
| العربي ظاهر مقلوب أو حروف مفكوكة | محرك النص الشرق أوسطي مش مفعّل — شوف فوق |
| كليبات زيادة عن الاقتباسات | عادي، الزيادة بتتساب من غير استخدام والأداة بتقولك عددها |
