# مولّد كروت الاقتباسات

الملف: **`QuoteCards.jsx`**

بياخد **كومب قالب واحد** ويعمل منه **نسخة لكل اقتباس** — كل نسخة بفيديو متحدث مختلف ونص اقتباس مختلف.

---

## ١. اختار الكومب اللي بترندره

**مهم:** اختار الكومب النهائي اللي بترندره (زي `RENDER-LEFT` أو `EQTBAS-Right`) — **مش** أي كومب جوّاني.

الأداة بتدوّر على الطبقات **جوه الكومب وجوه كل الكومبات اللي جواه كمان**. فلو القالب بتاعك مبني على كومبات زي:

- `REPLACE-FOOTAGE` ← مكان فيديو الضيف
- `REPLACE-PARAGRAPH` ← مكان نص الاقتباس

هتلاقيهم في القوايم مكتوبين بالمسار الكامل كده:

```
RENDER-LEFT  >  REPLACE-FOOTAGE  >  1: guest
```

والأداة بتختارهم **لوحدها** لو أسماءهم فيها `FOOTAGE` أو `guest` للفيديو، و`PARAGRAPH` أو `quote` للنص.

> **القالب نفسه مش بيتغير أبداً.** كل كرت بيتعمل كنسخة مستقلة.

### والكومبات الجوّانية بتتكرر كمان

دي أهم نقطة: لو الفيديو جوه `REPLACE-FOOTAGE`، فتكرار الكومب الخارجي لوحده **مش كفاية** — التسع كروت هيشاركوا نفس الكومب، وأول ما تغيّر واحد يتغيروا كلهم.

الأداة بتكرّر **سلسلة الكومبات كلها** لكل كرت:

```
RENDER-LEFT 01  →  REPLACE-FOOTAGE 01  +  REPLACE-PARAGRAPH 01
RENDER-LEFT 02  →  REPLACE-FOOTAGE 02  +  REPLACE-PARAGRAPH 02
```

والكومبات اللي مالهاش علاقة (عناصر، خلفيات) بتفضل مشتركة زي ما هي — عشان الـ Project panel ميبقاش فوضى.

## ٢. رتّب الكليبات بالترتيب

**ترتيب الملفات في الفولدر هو اللي بيحدد مين يظهر في أي اقتباس:**

| الكليب | يروح لـ |
|---|---|
| أول كليب | الاقتباس ١ |
| تاني كليب | الاقتباس ٢ |
| تالت كليب | الاقتباس ٣ |
| … | … |

فأسهل حاجة تسمّي الملفات بأرقام:

```
Aktbas/
   01_دلال.mp4
   02_مشينش.mp4
   03_محارمة.mp4
   ...
```

الترتيب طبيعي ومظبوط: `clip2` بييجي قبل `clip10`، مش بعده.

## ٣. التفريغ — ولماذا لا يشتغل لوحده

كتير من القوالب بتفرّغ الضيف بـ **Roto Brush** (في ملف المشروع اسمه الداخلي `ADBE Samurai`، وممكن يكون متسمّي أي اسم زي `Object Matte`).

**ضربات الروتو دي مرسومة بالإيد على كليب معيّن.** أول ما تبدّل الفيديو، الضربات بتبقى بلا معنى — والتفريغ بيقف. **ومفيش سكربت في الدنيا يقدر يعيد رسمها**، لأن Roto Brush مالوش واجهة برمجية في After Effects.

### الحل: تدّي القالب نسخة مفرّغة جاهزة

القوالب اللي بالشكل ده بتسيب مسار تاني جاهز — كومب زي `REPLACE-ALPHA-FOOTAGE` — بس **مقفول** (الطبقات بتاعته عينها مقفولة) لأن الافتراضي إنك تستخدم الروتو.

فعّل خيار:

> **Switch the template over to the cut-out clip**

وهو بيعمل حاجتين لكل كرت:
1. **بيفتح عين الطبقات** اللي بتعرض كومب الـ alpha
2. **بيقفل إفكت الـ Roto Brush** على طبقة الضيف، لأنه بقى بيأذي مش بيفيد

---

## ٤. الفيديو الأصلي **و** النسخة المفرّغة مع بعض

قوالب زي `IQTEBAS` بتحتاج **الاتنين**، مش واحد بدل التاني:

| الكومب | يتحط فيه | دوره |
|---|---|---|
| `REPLACE- FOOTAGE` | **الفيديو الأصلي** بخلفية اللوكيشن | الخلفية اللي بتبان ورا الدايرة |
| `REPLACE-ALPHA-FOOTAGE` | **النسخة المفرّغة** | الضيف مقصوص قدام الدايرة |

فالإعداد الصح:

```
Clips folder  →  فولدر الفيديوهات الأصلية
Alpha clips   →  فولدر النسخ المفرّغة
Video layer   →  ... > REPLACE- FOOTAGE > الطبقة اللي جواه
Alpha layer   →  ... > REPLACE-ALPHA-FOOTAGE
```

### الكومب الفاضي

كتير من القوالب بتسيب `REPLACE-ALPHA-FOOTAGE` **فاضي خالص (صفر طبقات)** — مستنيك تحط فيه.

الأداة بتتعامل مع ده: بتعرض الكومب الفاضي في القايمة كده:

```
RENDER-LEFT  >  REPLACE-ALPHA-FOOTAGE   (EMPTY comp - the clip gets added here)
```

اختاره عادي، وهي **هتضيف** الكليب جواه بدل ما تحاول تستبدل طبقة مش موجودة.

## ٥. التفريغ بطريقة تانية (لو قالبك مش بالشكل ده)

**السكربت مش بيقدر يعمل روتوسكوب.** Roto Brush مالوش واجهة برمجية في After Effects خالص.

بس قالبك عامل حساب ده: فيه كومب `REPLACE-ALPHA-FOOTAGE` وملف `ALPHA-FOOTAGE.mov` — يعني المصمم متوقع إنك تديله **نسخة مفرّغة جاهزة** لكل ضيف.

فالأداة دلوقتي بتقبل **فولدر تاني للنسخ المفرّغة**:

```
Aktbas/                    ← الكليبات العادية
   Aktbas_001.mov  →  الاقتباس ١
   Aktbas_002.mov  →  الاقتباس ٢

Aktbas_Alpha/              ← النسخ المفرّغة، بنفس الترتيب
   Aktbas_001_alpha.mov
   Aktbas_002_alpha.mov
```

حط مسار الفولدر التاني في خانة **Alpha clips**، واختار الطبقة من **Alpha layer** (بتتحدد لوحدها لو اسمها فيه `alpha` أو `matte`).

### لو كليباتك نفسها فيها alpha

مش محتاج فولدر تاني خالص — حط الكليبات المفرّغة في خانة **Clips folder** عادي.
بس خلي بالك من قايمة **Read a clip's alpha as**:

| اللي شايفه | اختار |
|---|---|
| التفريغ سليم | `let After Effects decide` (الافتراضي) |
| هالة بيضا حوالين الشخص | `Premultiplied – matted with WHITE` |
| هالة غامقة حوالين الشخص | `Premultiplied – matted with BLACK` |

واللوج بيكتبلك التفسير اللي اتاخد لكل كليب.

**إزاي تعمل النسخ المفرّغة؟** أي طريقة تريحك: Roto Brush يدوي، أو أداة تفريغ بالذكاء الاصطناعي، أو DaVinci Magic Mask. الأداة بس بتحط الملف الصح في الكرت الصح.

> لو سبت خانة Alpha فاضية، الكروت هتشتغل عادي بس بالتفريغ الأصلي بتاع القالب.

## ٦. ملف الاقتباسات

الأداة بتقبل تلات صيغ:

| الصيغة | إزاي بتقرأها |
|---|---|
| `.csv` | بتاخد العمود اللي فيه أطول نصوص — يعني ملف `quotes.csv` اللي عملتهولك شغّال على طول |
| `.txt` | كل اقتباس في فقرة (سطر فاضي بينهم)، أو كل اقتباس في سطر |
| `.srt` | بتاخد سطر `# ...` اللي تحت كل توقيت |

## ٧. شغّل

1. افتح الكومب القالب
2. **File ← Scripts ← Run Script File…** ← اختار `QuoteCards.jsx`
3. في النافذة:
   - **Template comp** — الكومب القالب
   - **Clips folder** — فولدر الكليبات
   - **Quotes file** — ملف الاقتباسات
   - **Video layer** — طبقة الفيديو (بتتحدد لوحدها، غيّرها لو غلط)
   - **Text layer** — طبقة النص (بتتحدد لوحدها، أو اختار «اتركه» لو مش عايز يغيّر النص)
4. الجدول بيتملى **لوحده** أول ما التلات خانات تتحدد — كل اقتباس جنبه الكليب اللي هياخده. لسه مفيش حاجة اتعملت
5. **Create cards** — بيعمل الكروت

> لو الجدول فاضي والزرار مقفول، اضغط **Scan** يدوي. والسطر اللي تحت الجدول بيقولك السبب دايماً.

الكروت كلها بتتحط في فولدر واحد في الـ Project panel اسمه `<اسم القالب> - cards`.

## اللي بيحصل في كل كرت

- نسخة من الكومب القالب باسم `اقتباس 01`، `اقتباس 02`، …
- فيديو المتحدث اتبدّل في نفس الطبقة ← **الماسك والإفكتات والتحريك كلهم زي ما هم**
- نص الاقتباس اتكتب ← **الخط واللون والحجم والمحاذاة زي ما هم**
- توقيت الكليب بيترجّع لبدايته، وبيتظبط على مقاس الفريم
- لو فعّلت خيار الماتّ: طبقة `[MATTE]` فوق الفيديو، متوصّلة كـ alpha track matte مع Simple Choker و blur لضبط الحواف

> **خيار الماتّ مقفول افتراضياً دلوقتي.** لو القالب بتاعك أصلاً فيه ماتّ للضيف (زي طبقة `Opject MAtte on the guest`)، سيبه مقفول — الأداة مش محتاجة تعمل واحد تاني.

`Ctrl+Z` مرة واحدة بترجّع كل الكروت.

## مهم للنص العربي

عشان العربي يظهر صح، لازم محرك النص الشرق أوسطي مفعّل:

**Preferences ← Type ← Text Engine ← South Asian and Middle Eastern**

لو كان مقفول، فعّله وأعد تشغيل After Effects **قبل** ما تشغّل الأداة.

## لو حاجة مظبطتش

| المشكلة | الحل |
|---|---|
| `-- no clip --` في عمود Clip | عدد الكليبات أقل من عدد الاقتباسات. زوّد كليبات أو قلّل اقتباسات |
| `The template comp has no footage layer` | الكومب المختار مفيهوش طبقة فيديو. اتأكد إنك مختار الكومب الصح |
| `-- no text layer anywhere in this comp --` | مفيش طبقة نص لا في الكومب ولا في أي كومب جواه. غالباً النص **shape layer** مش text layer |
| **الكرت طالع أسود** | القالب كان فيه كليب طويل متقصوص من نقطة جوّه، فالطبقة بتقرا من مكان بعد نهاية كليبك الجديد. فعّل **Start each clip at its own beginning** — ده بالظبط اللي بيحلها |
| الفيديو صغير في نص الفريم | الكومب 4K والكليب 1080p. فعّل **Fit the clip to its comp frame** |
| الشخص مظهرش في الكرت | غالباً اخترت الكومب الغلط. اختار الكومب النهائي اللي بترندره (`RENDER-LEFT`)، واتأكد إن **Video layer** مختار عليه الطبقة اللي مسارها فيه `REPLACE-FOOTAGE` مش عنصر خلفية |
| الاقتباس اتكتب مكان اسم المتحدث | الأداة بقت تختار طبقة النص اللي فيها **أطول كلام** (جسم الاقتباس). وكل طبقة في القايمة مكتوب جنبها نصها الحالي عشان تشوف بعينك قبل ما تضغط |
| الكلام مقصوص وطالع بره البوكس | فعّل **Shrink the type until the quote fits its text box**. ولو الطبقة **point text** مش box text، الأداة مش هتعرف تظبطها وهتقولك — حوّلها لـ box text في القالب |
| **هالة بيضا حوالين الشخص** | كليبك premultiplied بالأبيض بس بيتقرا straight. من قايمة **Read a clip's alpha as** اختار **Premultiplied – WHITE** |
| **هالة غامقة حوالين الشخص** | نفس الحكاية بس بالأسود — اختار **Premultiplied – BLACK** |
| الضيف مفرّغ في القالب بس مش مفرّغ في الكروت | القالب بيستخدم Roto Brush — شوف قسم ٣ فوق. مفيش حل غير إنك تدّيه نسخ مفرّغة جاهزة وتفعّل خيار التحويل |
| الشخص مش مفرّغ من خلفيته | شوف قسم «التفريغ» فوق. والأداة بقت تحذّرك في سطر الحالة لو القالب فيه مكان للتفريغ وإنت سايبه فاضي |
| ملف اللوج أو التقرير طالع **فاضي (صفر بايت)** | إذن الكتابة مش مفعّل. `Settings ← Scripting & Expressions ← Allow Scripts to Write Files and Access Network`. الأداة بقت تكتشف ده وتقولك بدل ما تديك ملف فاضي |
| **مش عارف أخد الـ alpha ولا الكليب الأصلي؟** | الرسالة اللي بتظهر بعد ما يخلص بتقولك بالنص: `Alpha -> ...` أو `Alpha -> NOT SWAPPED`. وكمان مكتوبة في ملف اللوج لكل كرت |
| النص مش بيتغير | اختار طبقة النص الصح من **Text layer** — لو سايبها على «leave the text alone» مش هيتكتب حاجة. ولو النص عليه كي فريمز، الأداة بتسيبه وبتكتب ده في اللوج |
| العربي ظاهر مقلوب أو حروف مفكوكة | محرك النص الشرق أوسطي مش مفعّل — شوف فوق |
| كليبات زيادة عن الاقتباسات | عادي، الزيادة بتتساب من غير استخدام والأداة بتقولك عددها |
