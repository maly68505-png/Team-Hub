# من استمارة البروديوسر لكروت الاقتباسات

الملف: **`EpisodeForm.jsx`**

بياخد استمارة البروديوسر الأسبوعية زي ما هي، وبيطلّعلك الملفين اللي `QuoteCards.jsx` بيقراهم. من غير ما تكتب اقتباس أو صفة بإيدك.

---

## الدورة الأسبوعية

```
استمارة البروديوسر  →  EpisodeForm  →  فولدر الحلقة  →  QuoteCards  →  الكروت
```

**في After Effects مفيش حاجة بتتغير.** نفس السكربتات، نفس القالب. اللي بيتغير كل أسبوع فولدر فيه ملفين نص.

---

## ١. شغّل الأداة

**File ← Scripts ← Run Script File…** ← اختار `EpisodeForm.jsx`

> ⚠️ **مش `File ← Import`** — ده للفيديوهات بس وهيرفض الملف.

---

## ٢. انسخ الاستمارة

الأداة **مش بتفتح ملفات PDF ولا Word**. ومفيش سكربت يقدر — After Effects مفيهوش قارئ للصيغتين دول أصلاً.

**المربع الكبير مستني النص، مش الملف.**

### إزاي تطلّع النص صح

| الطريقة | إزاي | النتيجة |
|---|---|---|
| **اطلب ملف Word من البروديوسر** | الاستمارة اتكتبت في برنامج قبل ما تتحول PDF | ✅ الأنضف |
| **Google Docs** | ارفع الـ PDF على Drive ← كليك يمين ← Open with ← Google Docs | ✅ بيعيد بناء الجداول |
| **Word** | افتح الـ PDF بـ Word مباشرة، وافق على التحويل | ✅ |
| **نسخ من الـ PDF مباشرة** | Preview ← `Cmd+A` ← `Cmd+C` | ❌ **بيكسّر الجداول** |

### ليه النسخ المباشر من الـ PDF بيفشل

الـ PDF مبيحفظش الجدول كجدول — بيحفظ مواضع حروف على صفحة. فلما تنسخ:

- كل خانة بتنزل في سطر لوحدها
- `( 19 )` بيتقسم لتلات أسطر: `)` و `19` و `(`
- الروابط بتتقطّع لأربع حتت

**ومفيش أداة تقدر ترجّع ده تاني.** المعلومة ضاعت وقت النسخ.

الأداة بتكتشف ده وبترفض تحفظ، وبتقولك:

> **اللصق ده اتكسّر** — طلع منه ٨ «اقتباس»، بعد ما اتشال ٤٥ سطر كانوا روابط أو علامات

### 🔴 وانسخ جدول الاقتباسات وقايمة الضيوف بس

الاستمارة فيها جدول تاني للمعادلات البصرية **مليان روابط صور**. لو نسخت الاستمارة كلها، الروابط دي بتتقطّع لمئات الفتات وبتلخبط الأداة.

ظلّل من أول `( 1 )` لحد آخر اقتباس، وبعدين قايمة الضيوف.

## ٣. شكل الاستمارة اللي بتتقرا

### الاقتباسات — لازم تكون مرقّمة

```
( 1 ) السلطة تُريد من خلال الانتخابات أن تجدد شرعيتها السياسية        11:06
( 2 ) من المحتمل تأجيل الانتخابات في ظل الواقع الذي تعيشه الأراضي     29:35
```

**الرقم والتوقيت بيتشالوا** — الرقم هو رقم الصف، والتوقيت للمساعدة بتاعتك. ولا واحد فيهم بيتكتب على الكرت.

بتقبل كل الأشكال دي:

| الشكل | |
|---|---|
| `( 1 ) ...` | ✅ |
| `1) ...` | ✅ |
| `1- ...` | ✅ |
| `[2] ...` | ✅ |
| `( ١ ) ...` بالعربي | ✅ |

> **لو الاستمارة مرقّمة، الأداة بتاخد المرقّم بس.** أي سطر تاني بتعتبره عنوان جدول أو تنسيق — وده بيمنع عنوان زي «أبرز الاقتباسات» إنه يتقرا كأنه الاقتباس رقم ١ ويزحزح الكروت كلها.

### الضيوف — تحت سطر فيه كلمة «الضيوف»

```
الضيوف:
الدكتورة دلال عريقات — عضو المجلس الثوري لحركة فتح
محمد مشينش — محلل سياسي وعضو الأمانة العامة للمؤتمر الشعبي
الدكتور إيهاب محارمة — باحث في المركز العربي للأبحاث
```

**الشرطة مش شرط.** Word و Google Docs بيعتبروا نقط القوائم تنسيق مش حروف، فبتختفي وقت النسخ — والأداة بقت تقرا القايمة من غيرها.

| بين الاسم والصفة | |
|---|---|
| شرطة `—` | ✅ الأفضل |
| فاصلة `،` | ✅ بتشتغل |

> **الشرطة أهم من الفاصلة**، لأن الصفة نفسها ممكن تكون فيها فواصل — زي «عضو المجلس الثوري لحركة فتح، وأستاذة الدبلوماسية».

القايمة بتنتهي عند: عنوان القسم اللي بعدها، أو اقتباس مرقّم، أو فقرة طويلة.

## ٤. اضغط Read وراجع

هتشوف **جدولين**:

| الجدول | المفروض تشوف فيه |
|---|---|
| الاقتباسات | سطر لكل اقتباس، **كلام مفهوم** |
| الضيوف | اسم وصفة لكل ضيف |

**لسه مفيش حاجة اتكتبت.**

### علامات إن اللصق طلع غلط

- روابط في عمود الاقتباسات
- أرقام أو حروف لوحدها
- عدد اقتباسات أكبر بكتير من الحقيقي
- **جدول الضيوف فاضي**

---

## ٥. مين قال إيه

### 🔴 تلات أرقام مختلفة — دي أكتر حاجة بتلخبط

| الرقم | من إيه لإيه | مداه |
|---|---|---|
| **رقم الاقتباس** | صف في `quotes.csv` | ١ … ٩ |
| **رقم الكليب** | الكليب في الفولدر — **أول كليب ← الاقتباس ١** | ١ … ٩ |
| **رقم الضيف** | مكان الضيف في `episode-info.txt` | **١ … ٣ بس** |

**خانة `Who said what` بتاخد رقم الضيف — مش رقم الكليب ولا رقم الاقتباس.**

رقم الاقتباس ورقم الكليب مربوطين ببعض أوتوماتيك (الكليب الأول للاقتباس الأول)، ومش بتتدخل فيهم. اللي بتحدده انت هو: **الاقتباس ده مين اللي قاله من التلاتة؟**

```
2,1,3,3,1,2,3,2,2
│ │ │
│ │ └─ الاقتباس ٣ ← الضيف رقم ٣ (محارمة)
│ └─── الاقتباس ٢ ← الضيف رقم ١ (دلال)
└───── الاقتباس ١ ← الضيف رقم ٢ (مشينش)
```

> **وتقدر تكتب جزء من الاسم بدل الرقم** لو ده أوضح ليك:
> `مشينش,دلال,محارمة,محارمة,دلال,مشينش,محارمة,مشينش,مشينش`

### وشوفه بعينك قبل ما تحفظ

جدول الاقتباسات فيه عمود **الضيف**، وبيتملى **وانت بتكتب**:

| # | Timecode | الضيف | Quote |
|---|---|---|---|
| 1 | 11:06 | محمد مشينش | السلطة تُريد من خلال الانتخابات… |
| 2 | 29:35 | الدكتورة دلال عريقات | من المحتمل تأجيل الانتخابات… |
| 3 | 31:22 | الدكتور إيهاب محارمة | هذه الانتخابات إن لم تتم… |

| اللي تشوفه في العمود | معناه |
|---|---|
| اسم الضيف | ✅ مظبوط |
| `— ؟ —` | لسه مكتبتش رقم للاقتباس ده |
| `⚠ "5" مش في القايمة` | كتبت رقم مفيش ضيف بيه |

**ده اللي هيتكتب على الكرت بالظبط.** لو العمود مظبوط، الكروت هتطلع مظبوطة.

## ٥ب. تفاصيل

**الاستمارة عمرها ما بتقول مين قال كل اقتباس.** دي الحاجة الوحيدة اللي مش مكتوبة في الورق، ومحدش يقدر يستنتجها — لازم حد شاف الحلقة.

في خانة **Who said what** اكتب رقم الضيف لكل اقتباس بالترتيب:

```
2,1,3,3,1,2,3,2,2
```

**تسع حروف بدل ما تكتب أسامي وصفات طويلة تسع مرات.**

الترتيب اللي ظاهر بيه الضيوف في الجدول هو أرقامهم: أول واحد `1`.

> سيبها فاضية لو مش متأكد دلوقتي، واملا العمود في الملف بعدين.

---

## ٦. Save into a folder

بيكتبلك ملفين:

```
quotes.csv          الاقتباسات + رقم الضيف لكل واحد
episode-info.txt    الضيوف بأسماءهم وصفاتهم
```

**بترميز UTF-8 من جوه After Effects** — يعني:

❌ مفيش Numbers · ❌ مفيش `Export To → CSV` · ❌ مفيش عربي مكسّر

## ٧. كمّل الفولدر وشغّل QuoteCards

```
EP28/
   Aktbas/                 ← الكليبات، مرقّمة بالترتيب
   quotes.csv              ← من EpisodeForm
   episode-info.txt        ← من EpisodeForm
   QuoteCards_setup.txt    ← انسخه من حلقة الأسبوع اللي فات
```

**ترتيب الكليبات هو اللي بيحدد مين يظهر في أي اقتباس.** أول كليب ← الاقتباس ١.

وبعدين: **File ← Scripts ← Run Script File…** ← `QuoteCards.jsx` ← اختار **Clips folder** و **Quotes file** ← **Create cards**.

📄 تفاصيل الأداة دي كلها في **[QUOTECARDS-AR.md](QUOTECARDS-AR.md)**

## لو حاجة مظبطتش

| الرسالة أو المشكلة | السبب والحل |
|---|---|
| **اللصق ده اتكسّر** | نسخت من الـ PDF مباشرة. عدّيه على Google Docs أو Word — شوف قسم ٢ |
| **مفيش قايمة ضيوف!** | نسخت الاقتباسات بس. الصق قايمة الضيوف تحتيها في نفس المربع |
| الأداة رفضت ملف PDF | صحيح — After Effects مفيهوش قارئ PDF. انسخ النص، مش الملف |
| `No quotes found` | الاقتباسات مش مرقّمة، أو مفيش حاجة في المربع |
| عدد الاقتباسات أقل من الحقيقي | التظليل مأخدش آخر صف. راجع وانسخ تاني |
| الكرت مكتوب عليه **رقم** مكان اسم الضيف | مفيش `episode-info.txt` جنب ملف الاقتباسات. الأداة بقت تسيب الاسم فاضي وتحذّرك بدل كده |
| الملفات مش بتتكتب | إذن الكتابة مقفول: `Settings ← Scripting & Expressions ← Allow Scripts to Write Files and Access Network` |
| الاستمارة **سكان** (صورة) | `Cmd+A` مش هيظلل حاجة — الصفحة صورة مفيهاش نص. اطلب الملف الأصلي من البروديوسر |
