# التشغيل السريع — نسخة "شغّل وخلاص"

الملف المطلوب: **`PersonReplacer_Auto.jsx`**

> مش محتاج تثبيت، ومش محتاج تظبط أي إعدادات. الملف بيلاقي كل حاجة لوحده.

---

## ١. رتّب الفولدر (مرة واحدة بس)

حط ملف المشروع وملف التوقيتات وفولدر الفيديوهات في مكان واحد:

```
Project AE/
  MyProject.aep          ← ملف المشروع
  script.srt             ← ملف التوقيتات
  videos/                ← فولدر فيديوهات الأشخاص
      PERSON_A_take1.mp4
      PERSON_B_take3.mp4
```

**مهم:** اسم الشخص في ملف `script.srt` لازم يكون موجود في اسم ملف الفيديو.
يعني `PERSON_B` في السكربت يلاقي `PERSON_B_take3.mp4`.

الفولدر مش لازم يكون اسمه `videos` بالضبط — الأداة بتقبل كمان:
`footage` / `clips` / `people` / `persons` / `media`.
ولو ملقتش أي واحد منهم، بتدوّر على أي فولدر فيه ملفات فيديو.

---

## ٢. شغّل السكربت

دي الخطوة اللي كانت واقفة معاك — بالظبط بالترتيب:

| # | تعمل إيه |
|---|---|
| ١ | **احفظ المشروع** أولاً (`Ctrl+S` / `Cmd+S`) — مهم جداً، لأن الأداة بتبدأ البحث من مكان ملف المشروع |
| ٢ | افتح الكومب اللي عايز تشتغل عليه (اضغط عليه دبل كليك في الـ Project panel) |
| ٣ | من القائمة العلوية: **File ← Scripts ← Run Script File…** |
| ٤ | اختار ملف `PersonReplacer_Auto.jsx` واضغط Open |

> ⚠️ **مش File ← Import.** الاستيراد للفيديوهات بس.
> السكربتات بتتشغّل من **File ← Scripts**.

---

## ٣. راجع واضغط زرار واحد

هتظهرلك نافذة فيها اللي لقته:

```
OK   Comp:           Main Comp   (25 fps)
OK   Videos folder:  .../Project AE/videos   (4 clips)
OK   Script file:    .../Project AE/script.srt
```

وتحتها جدول بكل مقطع: التوقيت، اسم الشخص، الملف اللي اختاره، والطبقة اللي هيشتغل عليها.

- كل حاجة مكتوب جنبها `OK` ← اضغط **Replace now**
- لو مكتوب `--` جنب حاجة ← اضغط الزرار اللي تحت (**Videos folder…** أو **Script file…**) وحدّدها بنفسك مرة واحدة

**لحد ما تضغط Replace now، مفيش أي حاجة بتتغير في مشروعك.**

---

## ٤. بعد ما يخلص

- هتظهر رسالة: كام مقطع اتبدّل وكام اتخطّى
- ولو حصل أي خطأ: **`Ctrl+Z` مرة واحدة بترجّع كل حاجة**
- التفاصيل الكاملة بتتكتب في ملف `script_replace_log.txt` جنب ملف التوقيتات

## لو حاجة مظبطتش

| المشكلة | السبب والحل |
|---|---|
| زرار **Apply** مقفول (رمادي) | معناه إن عدد المقاطع اللي اتقرأت = صفر. شوف السطر اللي تحت الجدول، هيقولك السبب |
| اخترت ملف **PDF** أو **Word** كـ Script file | الأداة بتقرأ نصوص عادية بس. افتح الملف، وانسخ التوقيتات في ملف `.txt` أو `.srt` |
| `Can't import file... unsupported filetype` | إنت استخدمت **File ← Import**. استخدم **File ← Scripts ← Run Script File…** |
| مش لاقي **Run Script File** في القائمة | تأكد إنك في After Effects نفسه مش Media Encoder، والقائمة تحت `File` مباشرة |
| `Videos folder: not found` | فولدر الفيديوهات بعيد عن ملف المشروع. اضغط زرار **Videos folder…** وحدّده |
| `Script file: not found` | ملف `.srt` مش موجود جنب المشروع. اضغط **Script file…** وحدّده |
| `-- no match --` في عمود Clip | اسم الشخص في السكربت مش موجود في اسم أي ملف فيديو. غيّر اسم الملف، أو اكتب في السكربت: `PERSON_B \| اسم_الملف.mp4` |
| `-- no layer --` في عمود Target layer | مفيش طبقة فيديو شغّالة في التوقيت ده في الكومب المفتوح. اتأكد إنك فاتح الكومب الصح وإن الطبقة مش مقفولة |
| الشخص جوه **precomp** | الأداة بتبدّل المصادر — لازم تفتح الـ precomp نفسه وتشغّل السكربت وإنت جواه |

## لو حبيت تثبّته بشكل دائم

انسخ الملف هنا، وبعدها هيظهر في قائمة **Window** على طول من غير ما تدوّر عليه كل مرة:

- **ويندوز:** `C:\Program Files\Adobe\Adobe After Effects <الإصدار>\Support Files\Scripts\ScriptUI Panels\`
- **ماك:** `/Applications/Adobe After Effects <الإصدار>/Scripts/ScriptUI Panels/`

بعد ما تنسخه، اقفل After Effects وافتحه تاني، وهتلاقيه في **Window ← PersonReplacer_Auto.jsx**.
